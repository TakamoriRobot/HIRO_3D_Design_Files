# H.I.R.O. 3D Design Files
This is the repository for the 3D files for Takamor HIRO's Mechanical Components. Both the components for H.I.R.O. Model TR-01-A, and our 100% DIY prototype H.I.R.O. GenZero Edition.

<img src="imgs/Two HIROs.jpg">

# H.I.R.O. Model TR-01-A

This folder has the .STEP files .STLs for the H.I.R.O. Model TR-01-A Robotics Dev Kit,  for anyone who would like to print, study, or modify the mechanical components. For more info click <a href = "https://shop.takamorirobot.com/products/h-i-r-o-model-tr-01-a-kit"> here</a>.

# H.I.R.O. GenZero

H.I.R.O. GenZero is our answer to "We have H.I.R.O. at home. H.I.R.O. GenZero is 100% DIY H.I.R.O. unit that you can 3D print at home and assemble using off the shelf parts.
