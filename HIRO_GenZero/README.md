# H.I.R.O. GenZero - "We Have H.I.R.O. at Home
DIY an entire H.I.R.O. unit  using only 3D printed parts and off the shelf parts. 

<h3>Materials</h3>

- 3D Printed Parts: Part files in this Repe

- Jumper Cables: https://www.amazon.com/dp/B01EV70C78?ref=nb_sb_ss_w_as-reorder_k8_1_10
- Breadboard: https://www.amazon.com/DEYUE-breadboard-Set-Prototype-Board/dp/B07LFD4LT6
- Solid core jumper cables: https://www.amazon.com/WWZMDiB-Lengths-Assorted-Preformed-Breadboard/dp/B0BWGZRGYP
- Micro USB Cable: https://www.amazon.com/Micro-USB-Cable-Android-SMALLElectric/dp/B01N9P860N
- Raspberry Pico 2W: https://www.sparkfun.com/raspberry-pi-pico-2-w-with-headers.html

<h3>Equipment</h3>

- Laptop
- 3D Printer
